
## Этапы

1. **REPL** — интерактивный цикл, приглашение пользователя, разбор команд,
   заглушки `ls` и `cd`, обработка ошибок и `exit`.
2. **Конфигурация** — параметры `--vfs`, `--prompt`, `--script`, выполнение
   стартового скрипта с отображением команд и результатов.
3. **VFS** — загрузка JSON-образа в память, каталоги и файлы, Base64,
   команды `ls`, `cd`, `pwd`, `cat`, проверка структуры и обработка ошибок.

## Запуск финальной версии

Windows:

```powershell
py main.py --vfs vfs/full.json
```
С пользовательским приглашением и стартовым скриптом:
```powershell
py main.py --vfs vfs/full.json --prompt "demo$ " --script scripts/startup.txt
```
Минимальная файловая система:
```powershell
py main.py --vfs vfs/minimal.json
```
## Команды финальной версии

- `ls [ПУТЬ]` — показать содержимое каталога.
- `cd [ПУТЬ]` — перейти в каталог; без аргумента перейти в `/`.
- `pwd` — показать текущий виртуальный путь.
- `cat ФАЙЛ...` — вывести содержимое файла или файлов.
- `exit` — завершить эмулятор.

Поддерживаются одинарные и двойные кавычки в аргументах, а также пути `/`,
`.` и `..`. Команды работают только с виртуальной файловой системой в памяти.
